# Brand：Ensemble

## 1. 品牌定位

| 项 | 定义 |
|----|------|
| 产品名 | **Ensemble** |
| 产品类别 | 跨平台 Agent 编排桌面应用 |
| 核心承诺 | 看清协作、控制执行、及时介入 |
| 气质 | 简约、精确、可信、克制 |

产品名保留，但不将名称词源转译成界面主题、装饰或交互隐喻。

---

## 2. 对外表达

英文主描述：

> Orchestrate agents with clarity and control.

中文主描述：

> 清晰编排和掌控 Agent 协作。

短描述：

> Ensemble 把 Agent 的职责、执行关系、交付过程和用户待办集中到一个可操作的组织画布中。

---

## 3. 品牌视觉

- 视觉不依赖产品名的字面联想
- 默认浅色、炭黑结构和朱红主信号
- Logo 与应用图标后续单独设计
- Logo 不承担状态、Runner 或 Handoff 的业务含义
- 品牌表达保持克制，不在工作界面加入营销文案
- 主题可以变化，品牌识别不依赖固定背景颜色

---

## 4. 用语规范

| 使用 | 不使用 |
|------|--------|
| Workspace | 项目、Run、Session 混称 |
| Runner | 底层模型、固定 pi 模式 |
| Role | 画布中的具体 Agent 实例 |
| Seat | Role 模板本身 |
| Group | 任意 Workflow 分段或 Workspace |
| Handoff | 无含义的动画连线 |
| Attention | 所有事项都叫通知 |
| Inspector | 永久详情栏或卡片墙 |
| Run | Workspace 或编排模板 |
| Artifact | 任意日志文本 |

单 Agent 是完整使用路径，不称为降级模式。

---

## 5. 界面文案

- 使用动作和结果，不使用抽象宣传词
- 不向用户暴露 Mock、Fixture、LOD 等开发术语
- 不把内部枚举直接作为可见状态
- 一次会话只使用一种 UI 语言
- Runner 和技术 ID 只在需要配置或诊断时显示
- 所有可见文案遵守 [ssot/i18n.md](ssot/i18n.md)
