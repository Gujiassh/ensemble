# 参考与竞品

## 定位空白

市面常见能力碎片化：

1. 角色剧本（Crew）  
2. 状态 / 交付物可视化  
3. 可插拔 coding CLI  

Ensemble 叠加为：

> **Living Org Canvas（组织/OA/冒泡）× 管道传信 × Runner 可插拔 × Staffing 可挂树**

## 角色 / 虚拟软件公司

| 参考 | 可学 | 我们不照抄 |
|------|------|------------|
| ChatDev | 角色、阶段、回放 | 主界面不做对话瀑布 |
| MetaGPT | SOP、中间产物 | 不只 CLI 出仓库 |
| Atoms / MGX | AI 员工叙事 | 要真 org 树与 runner |
| CrewAI | 协作语义 | Crew ≠ 产品门面 |

## 工程控制台
