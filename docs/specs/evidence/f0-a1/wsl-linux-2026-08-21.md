## Production Defects Repaired

1. Existing-file data roots were rejected by `create_dir_all` as generic `data_root_create`, leaving the intended `data_root_not_directory` branch unreachable. Bootstrap now inspects an existing root before creation and returns the stable specific code.
2. Token validation counted trailing token68 `=` padding toward the minimum, so a padding-only file could satisfy the length check. Validation now requires at least 43 non-padding material characters and rejects padding-only input.
3. Ready publication preceded the shutdown future's first poll and authenticated router construction. An immediate post-ready `SIGTERM` could therefore apply the platform default termination before the handler registered. Bootstrap now constructs the router and polls the shutdown future once before atomically publishing ready. A dedicated 24-trial real-process regression observes ready and immediately signals without health work, then proves same-root restart; it repeatedly exercises this scheduler-sensitive window without claiming deterministic proof of every possible schedule. The separate replacement-ready test proves only descriptor ownership preservation.
4. Ready publication accepted paths inside the canonical data root, including `.ensemble-runtime.lock`; atomic replacement could swap out the inode carrying the datastore flock and permit a second same-root Runtime. Ready targets now canonicalize through their existing parent, reject equal/inside-root paths and reserved lease filenames, and carry a lifetime-held persistent sibling lease. Shared active paths fail without mutation; stale descriptors are replaceable only after lease release.
5. Axum graceful shutdown had no deadline, and merely timing out/dropping its top-level Serve future left detached per-connection tasks and sockets alive in-process. F0-A1 now owns acceptance and every Hyper HTTP/1.1 connection in a Tokio `JoinSet`: shutdown stops accept, broadcasts graceful shutdown, waits one second, then aborts and joins all remaining tasks before ready/lease cleanup. In-process, 48-client accept-pressure, and binary socket-closure regressions prove the ownership boundary. Protocol upgrades are disabled so no upgrade task can escape the registry. This does not alter later business safe-quit semantics.
